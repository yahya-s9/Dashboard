# Daily Habit Tracker

The main habit tracker — a single self-contained `index.html` with no build step and no server.

Open `index.html` in a browser (or add it to an iPhone Home Screen) to check off daily habits and watch the cumulative graph climb.

Check-ins are stored only in that browser's `localStorage` (`daily-habit-tracker-v1`), so history does not sync across devices.

## Default habits (18)

- Islam: Memorize 1 page, Fajr, Dhuhr, Asr, Maghrib, Isha, Qadha (2x each prayer)
- Professional: Document wins, 1 LeetCode, 1 system design
- Academic: 15 min learning
- Entrepreneurship: Ship something
- Finances: Give $1
- Relationships: Call family
- Health: Sleep / wake early, Caloric deficit, Only water / coffee, 30 min workout

Habits can be added or removed in the app's edit mode.
